Webmail reverse proxy

Proxy a webmail app (SnappyMail, Roundcube, etc.) through Caddy with automatic HTTPS. The upstream runs separately — GoshPanel only configures the reverse proxy.

Setup notes

  1. Install SnappyMail or Roundcube on the upstream port (e.g. Docker on 8080).
  2. Set the hostname above and enable the proxy.
  3. Point DNS for the webmail hostname to this server.
  4. Apply orchestrator if Caddy is not auto-applied.
